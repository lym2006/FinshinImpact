# 代码规范

以 [`docs/example.py`](example.py) 为唯一模板，`ruff.toml` 管可机检项，本文管机器查不了的习惯。

## 文件骨架（自上而下）

```
# 路径注释 → 模块 docstring → 导入 → 常量 → __all__ → 业务 → 主入口 → __main__
```

1. 首行 `# 相对路径.py`，与文件实名（含 `_` 前缀）严格一致。
2. 模块 docstring：一行定位 + 空行 + 短横列表说职责。
3. 区块标题注释划分宏观分区，顺序固定：导入 → 全局常量与配置 → 对外暴露 → 核心业务逻辑 → 主程序入口 → 脚本直接运行入口。等号固定 20 个，无序号、无标点、无尾随空格，上下各空一行；函数内步骤用行内注释，不配区块标题。
4. 主入口永远在文件最底部；业务函数按调用者在上排列。

## Docstring

- 首行短定位语（名词或单动作），不塞流程。
- 标题与详情间空一行；详情写行为与"为什么"，不写实现步骤。
- 一行说得完就不开详情段；多行详情每行一句独立写完整，禁折行（同「注释」）。

## 注释

- 整行注释是分区，上方空一行；豁免：连续组非首行、块首（`:` `(` `[` `{` `,` 结尾）之后、docstring 之后。
- 行尾短尾注紧贴代码，与代码空两格。
- 叙述性文字一行写完，禁止折行：`#` 与 docstring 一律适用，逗号、分号、顿号之后都不许把半句劈到下一行；超长拆语义成短句，一句一行。
- 说"为什么"，不复述"做什么"；中文。
- 过期注释按 bug 处理，改码必改注。

## 命名与门面导出

| 对象 | 规则 | 例 |
| :--- | :--- | :--- |
| 包内实现文件 / 目录 | `_` 前缀，docstring 首行标「（内部实现）」 | `_connectivity.py` |
| 对外文件 / 目录 | 无前缀，不得标「内部实现」 | `lifecycle.py` |
| 模块私有常量 | 大写 + `_` 前缀 | `_MAX_RETRIES` |
| 对外导出常量 | 裸大写 | `LOGS_DIR` |
| 私有类型别名 | `_` 前缀 | `_FontType` |
| 函数 / 变量 | snake_case，私有加 `_` | `_apply_update` |
| 类 | PascalCase，私有加 `_` | `_Holder` |

- "对外"唯一标准：进 `__all__` 或被其他模块 import；否则一律 `_` 前缀。该标准对文件、目录、类、方法、变量、常量一致适用——仅由包门面 `__init__.py` 导入的子模块属内部实现，文件名加 `_` 并在 docstring 标注。
- 门面最小导出：包门面只代发多消费方符号；单一或极少数消费者的符号不进门面，子模块转正（去 `_`、摘「内部实现」标注），由调用方 `from package.module import symbol` 直连。
- 包内互用走相对直连，不绕自家门面，防循环依赖回流。

## 魔法数字与字符串

- 提为文件顶部私有常量，命名带单位语义，行尾注释换算值。
- 跨模块共用数值收进公共 utils 裸大写导出，禁止重复定义。
- 协议串（状态机等跨模块比较的短字符串）收进命名空间类（如 `RowStatus`），比较侧引用类属性，禁止裸写。

## 日志与文案

- 面板日志单行短句，源串禁止 `\n`；超长在源内隐式拼接，语义仍是一行。
- 多行结构化信息只走弹窗；面板不重复灌入，明细降 `DEBUG` 落文件。
- 弹窗文案 ≤4 行；高度随行数自适应撑开，不靠空首行土办法。
- 面板只记状态推进（正在…/…完成），结果长文不进面板。
- 用户可见文案收敛进 `src/messages/`（GUI）或就近 `messages.py`（Bot 话术），禁止 f-string 裸写业务话术；异常文案模板留在 exceptions 各族映射表；`_theme` 令牌只代理引用、不持有话术字面量。

## 文案类（src/messages/）

- 每域一个类 `XxxMessage`；域文件仅门面导入属内部实现，文件名带 `_` 且为类名 snake_case（`ConnectivityMessage` ↔ `_connectivity.py`）；类名已含域义则成员不再重复域前缀。
- 跨域同义文案单源一处定义，另一域直接引用，禁止字面复制。
- 每条成员行首注释标注使用位置。

## 类型注解

- 所有 `def`（含方法）的形参与返回值一律写注解，`__init__` 返回 `-> None`；局部变量类型不自明时补声明注解。
- 仅三类情况允许 `# type: ignore`，且行尾注明归类原因：
  - 不必要的注解：`self` / `cls`、简单 lambda。
  - 循环导入：正向引用先 `TYPE_CHECKING` + 字符串注解，仍解不出的才 ignore。
  - 对齐官方方法：重写 Qt / 三方基类回调（`closeEvent` 等），基类签名本身无提示。
- 纯 `super().__init__(*args, **kwargs)` 转发不为注解引入 `ParamSpec`；能收口写显式签名，收口不了的按上述豁免。

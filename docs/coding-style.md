# 代码规范

以 [`ruff.toml`](../ruff.toml) 管可机检项，本文管机器查不了的习惯。
本规范自 v1.0.0-alpha.1 起生效，v1.0.0-alpha.3.dev1 起废除区块标题。

## 文件骨架（自上而下）

```
# 路径注释 → 模块 docstring → 导入 → 常量 → 业务 → 主入口 → __main__
```

1. 首行相对路径 `# src/.../xx.py`，与文件名（含 `_` 前缀）严格一致。
2. 模块 docstring：一行定位 + 空行 + 短横列表说职责。
3. 禁用区块标题注释。导入、全局常量与配置、对外暴露、核心业务逻辑、主程序入口、脚本直接运行入口六类分区由骨架顺序唯一确定，标题属噪音。
4. 文件粒度取代标题：一文件一主题。函数太多或太长即拆包，按功能归子模块，文件名承载分区语义。
5. 语义分组（字体域、表格域等读者需要横向定位的段落）用单行普通注释 `# 分组名`，不带等号横线。
6. 非空门面（包 `__init__.py` 代发符号）才写 `__all__`；业务模块不写，调用方 `from package.module import symbol` 直连，需要本地私有名时 `import symbol as _symbol`。
7. 主入口永远在文件最底部，业务函数按调用者在上排列。

## 拆分粒度

- 触发线，命中任一即拆：单文件超 300 行，或同族顶层函数超 5～6 个；单类方法超 8～10 个；单函数体超 60 行评审、80 行硬拆。
- 下限：一个子模块至少两个同族成员，禁「一函数一文件」；例外仅门面 `__init__`、抽象 base、纯数据模型文件。
- 分类求精准，但精准到「一族放不下才分第二文件」，不是精准到一人一文件。
- 拆分只移动代码与改名，不改行为。

## Docstring

- 首行标题行：简单定语加名词（`Bot 管理器`）或简单动作（`网络探测`），不塞流程、不带标点符号，一行说得完就不开详情段。
- 修饰状语可作定语并入标题（`实例锁占用探测（静默）`→`实例锁占用静默探测`），或直接不写，无法自然并入降为 `-` 行。
- 标题与详情间空一行，详情段一行一个功能要点，一律 `-` 起头，具体实现与"为什么"下沉到函数体内的注释。
- 一行一句，行尾不写句号
- 括号或冒号想带的解释，要么降为一条 `-` 行，要么写进代码注释，不许留在标题。
- 禁止分号：一条事实一行，用 `-` 分行。
- 禁止折行：逗号、顿号后不许把半句劈到下一行，超长拆成短句，一句一行。

## 注释

- 函数与类定义一律不加前置注释，说明统一由 docstring 与函数体内部注释承担。
- 变量与常量可加注释：标识符类写"改名会波及谁"，度量类写换算值，不复述命名本身。
- 整行注释只允许两种：语义分组名（`# 字体域`）、代码内部的"为什么"。禁止区块标题与装饰横线。
- 整行注释紧贴其描述的代码，中间不空行；上方空一行，以下豁免：
  - 多行注释非首行
  - 块首（`:` `(` `[` `{` `,` 结尾）之后
  - docstring 之后
  - `__all__` 内部
- 行尾短尾注紧贴代码，与代码空两格，`Ruff` 可自动格式化。
- 原则上禁止连续多行注释，简化后并入一行，如内容过多无法合并允许多行。
- 过期注释按 bug 处理，改码必改注。
- 禁止分号、折行（同「Docstring」）。

## 命名与门面导出

| 对象 | 规则 | 例 |
| :--- | :--- | :--- |
| 包内实现文件 / 目录 | `_` 前缀 | `_connectivity.py` |
| 对外文件 / 目录 | 无前缀 | `lifecycle.py` |
| 模块私有常量 | 大写 + `_` 前缀 | `_MAX_RETRIES` |
| 对外导出常量 | 裸大写 | `LOGS_DIR` |
| 私有类型别名 | `_` 前缀 | `_FontType` |
| 函数 / 变量 | snake_case，私有加 `_` | `_apply_update` |
| 类 | PascalCase，私有加 `_` | `_Holder` |

- 私有内容标记 `_` 前缀后不额外写「内部实现」标注。
- "对外"唯一标准：进 `__all__` 或被其他模块 import，否则一律 `_` 前缀。文件、目录、类、方法、变量、常量一律适用。
- 仅由包门面 `__init__.py` 导入的子模块属内部实现，文件名加 `_` 前缀。
- `__all__` 只属于非空门面：包 `__init__.py` 代发多消费方符号才写；业务模块与纯转发门面不写，消费方直连子模块导入，本地需要私有名时 `import symbol as _symbol`。
- 门面最小导出：包门面只代发多消费方符号，单一或极少数消费者的符号不进门面，子模块转正（去 `_` 前缀），由调用方 `from package.module import symbol` 直连。
- 包内互用走相对直连，不绕自家门面，防循环依赖回流。
- 同源的散装模块级变量（常量、配置项、协议串）攒够三五件即收进命名空间类，不许裸变量持续堆积。
- `core/dto` 类型一律 `DTO` 后缀（如 `PrincipalDTO`、`MsgReferenceDTO`）。
- 词表按变更范围归层：与某 DTO 字段共变的进该 DTO 文件，横切适配层与存储的进 `core/domain`。
- 同域成员不重复域前缀：类名或裸常量前缀已表达域义，成员只写语义本体——`RowStatus.SKIP` 不写成 `ROW_STATUS_SKIP`，`ConnectivityMessage.TIMEOUT` 不写成 `_CONNECTIVITY_TIMEOUT`。
- 域与域靠语义区分，格式全文件一致：域外可见的裸常量一律 `DOMAIN_MEANING[_UNIT]`（如 `PUSH_MAX_RETRIES`、`CONNECT_TIMEOUT_MS`），私有加 `_` 前缀（如 `_PUSH_MAX_RETRIES`），禁止混用其他样式。

## 魔法数字与字符串

- 提为文件顶部私有常量，命名带单位语义，行尾注释换算值。
- 常量归属分两类：
  - 标识符类（文件名、目录名、字典键名、协议串——各方必须取同一个值）：单源一处定义，消费方直连引用，重复定义按 bug 处理。
  - 度量类（超时、尺寸、阈值——数值相等不构成同一契约）：谁用谁持有，禁止为数值巧合而抽公共常量制造虚假耦合。
- 协议串（状态机等跨模块比较的短字符串）收进命名空间类（如 `RowStatus`），比较侧引用类属性，禁止裸写。

## 日志与文案

- 面板日志单行短句，多行结构化信息只走弹窗，面板不重复灌入，明细降 `DEBUG` 落文件。
- 弹窗文案高度随行数自适应撑开，不靠空首行土办法。
- 面板只记状态推进，结果长文不进面板。
- 文案收敛：
  - `GUI` 可见文案收敛进 `src/messages/`，禁止 f-string 裸写业务话术。
  - `Bot` 对话话术收敛进 `src/plugins/messages.py`（`BotMessage`），插件间直连引用，禁止内联裸写。
  - 运行日志不属对话文案，不收敛，就地内联保持可 grep。
  - 异常文案模板在同文件就近写映射表。
  - `_theme` 令牌只代理引用、不持有话术字面量。

## 文案类（src/messages/）

- 每域一个类 `XxxMessage`。
- 域文件仅门面导入属内部实现，文件名带 `_` 且为类名 snake_case（`CheckMessage` ↔ `_check.py`）
- 类名已含域义则成员不再重复域前缀（同「命名与门面导出」）。
- 跨域同义文案单源一处定义，另一域直接引用，禁止字面复制。
- 每条成员行首注释标注使用位置。

## 类型注解

- 所有 `def`（含方法）的形参与返回值一律写注解，`__init__` 返回 `-> None`；局部变量类型不自明时补声明注解。
- 仅三类情况允许 `# type: ignore`，且行尾注明归类原因：
  - 不必要的注解：`self` / `cls`、简单 lambda。
  - 循环导入：正向引用先 `TYPE_CHECKING` + 字符串注解，仍解不出的才 ignore。
  - 对齐官方方法：重写 Qt / 三方基类回调（`closeEvent` 等），基类签名本身无提示。
- 纯 `super().__init__(*args, **kwargs)` 转发不为注解引入 `ParamSpec`；能收口写显式签名，收口不了的按上述豁免。
